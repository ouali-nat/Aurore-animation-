Personnage complet — JSON

Le modèle est construit en 3D : tête, visage, yeux, cheveux, torse, manches, bras, mains, jambes, chaussures et accessoires sont des objets distincts. Tu peux aussi modifier les propriétés non présentes dans les réglages rapides directement ici.

Exemples de propriétés : face.eyeScale, face.eyeSpacing, face.noseSize, hair.style, body.shoulderWidth, outfit.topColor, animation.type, animation.speed. Les modifications du catalogue restent dans cette session jusqu’à l’enregistrement JSON.
