Aide : format du JSON

actors : personnages { "A": { "char":"faucheur", "x":-4, "z":0, "hp":100, "name":"…", "power":"fire", "ai":true } }. char : faucheur, lancier, air, epeiste, samourai, bucheron, titan, archer, assassin, gardien, triton, mage, feu, eau, terre, foudre, glaive, hallebardier, duelliste, moine.

timeline : liste d'événements { "t":secondes, "actor":"A", "do":…, … }.
Actions : walk run dash (avec "to":[x,z] ou "to":"B"), jump, attack (target, dmg), cast (power, target, dmg, color), teleport (to:[x,z], behind:"B", random:true, away:true), block (dur), pose, idle.
Globales : camera (shot : wide, follow, close, top + target), text (text, dur), shake, end.

Pouvoirs : fire, water, dark, air, lightning (foudre qui tombe), earth (météore), beam (rayon), nova (onde). Personnalisés : "powers": { "inferno": { "base":"fire", "color":"#ff0000", "dmg":30 } }.
"ai": true (ou { "powers":[…], "aggr":0.8, "gap":0.4 }) : le personnage combat tout seul. Autres : seed, arena (rayon), duration. Les attaques de zone et projectiles peuvent être esquivés par téléportation.
