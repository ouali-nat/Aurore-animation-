Aurore Motion 🌱

Aide : format JSON

width height background duration (ms) loop (true/false)

Chaque élément de layers : shape (circle, rect, triangle, ring, ball, text), size ou width/height, color, x, y (centre), text, radius, delay, duration, loop, direction, easing.

keyframes : t de 0 à 1, puis x y scale scaleX scaleY rotate opacity blur color easing.

Easings : linear, ease, ease-in, ease-out, ease-in-out, spring, bounce, ou cubic-bezier(...).
