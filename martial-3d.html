Aide : format du JSON

actors : { "A": { "tone":"grey", "x":-3, "z":0, "hp":100, "name":"…", "h":1, "ai":true } }. tone : black, grey, white, red, blue ou "#rrggbb".

timeline : { "t":secondes, "actor":"A", "do":…, … }.
Déplacements : walk run dash ("to":[x,z] ou "to":"B" + gap), jump, teleport (to, behind:"B", random:true, away:true).
Coups : punch kick uppercut (projette en l'air) sweep (balayage) flykick (coup de pied volé) combo (3 coups), avec target et dmg facultatifs. Aussi block (dur), pose (victoire), idle.
Globales : camera (shot : wide, close, top + target), text (text, dur), shake, end.

"ai": true (ou { "aggr":0.8, "gap":0.4 }) : le personnage combat tout seul. Autres : seed, arena, duration. Un coup raté si l'adversaire s'est téléporté ou éloigné.
